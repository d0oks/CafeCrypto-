# CaféCrypto

Marchés & actualités crypto : prix en temps réel, graphique BTC, tendances, gagnants et perdants du jour.

Site : https://d0oks.github.io/CafeCrypto-/

## Déploiement (GitHub Pages)

1. Poussez tous les fichiers à la **racine** du dépôt.
2. `Settings` → `Pages` → Source : *Deploy from a branch* → branche `main`, dossier `/ (root)`.

## Passer à un domaine personnalisé plus tard

1. Ajouter un fichier `CNAME` contenant le domaine, et configurer le DNS chez le registrar.
2. Remplacer `https://d0oks.github.io/CafeCrypto-/` par le domaine dans `index.html` et `sitemap.xml`.
3. Dans `404.html`, remplacer `/CafeCrypto-/` par `/`.
4. Ajouter un `robots.txt` avec la ligne `Sitemap: https://votre-domaine/sitemap.xml`.
